# روتين | ROUTINE — Android

مشروع Flutter أولي قابل للتطوير لتطبيق تنظيم الروتين اليومي، بواجهة عربية RTL ووضع داكن.

## ما يتضمنه المشروع
- الرئيسية: مهام اليوم ومؤشر إنجاز يومي.
- الخطة الشهرية: تقويم تفاعلي مع مؤشرات المهام.
- مهامي: قائمة شاملة، تصفية، تعديل، حذف مع تأكيد.
- إنجازاتي: ملخص الشهر ومخطط آخر سبعة أيام.
- الإعدادات: تشغيل التذكيرات، وقت البداية والنهاية، وتيرة التذكير، وإظهار عدد المهام المتبقية.
- SQLite لحفظ المهام محلياً.
- إشعارات Android مجدولة محلياً ولا تعتمد على بقاء التطبيق مفتوحاً.

## المتطلبات
- Flutter SDK حديث (Dart 3.4 أو أحدث).
- Android Studio / Android SDK.
- جهاز Android أو محاكي.

## تشغيل المشروع
1. ثبّت Flutter وتحقق من الإعداد:
   `flutter doctor`
2. من مجلد المشروع نفّذ:
   `flutter create . --platforms=android`
   (إذا طلبت أداة Flutter تأكيد استبدال ملفات Android، احتفظ بملف `AndroidManifest.xml` المرفق).
3. نفّذ:
   `flutter pub get`
4. شغّل:
   `flutter run`

لبناء APK:
`flutter build apk --release`

المسار المتوقع:
`build/app/outputs/flutter-apk/app-release.apk`

## ملاحظات مهمة حول الإشعارات
- يطلب التطبيق إذن الإشعارات وإذن المنبهات الدقيقة عند التشغيل حيثما يدعم إصدار Android ذلك.
- تستخدم النسخة الحالية جدولة محلية مستقبلية لمدة 20 يوماً، ثم يعاد بناء الجدول عند فتح التطبيق أو تغيير الإعدادات. هذه آلية فعلية وليست مؤقتاً داخل الواجهة.
- Android Doze وإعدادات توفير البطارية والشركات المصنّعة قد تؤخر الإشعارات غير الدقيقة. يمكن للمستخدم السماح بالتنبيهات الدقيقة من إعدادات النظام إذا أراد دقة أعلى.
- لم يُجرَ بناء APK أو اختبار على جهاز فعلي في بيئة الإنشاء الحالية؛ يجب تنفيذ خطوات التشغيل والبناء أعلاه في بيئة Flutter قبل النشر.

## حدود النسخة الحالية
- إنشاء التكرار اليومي أو الأسبوعي ينشئ نسخ مهام فعلية ضمن الشهر الحالي، بدلاً من تخزين قاعدة تكرار ديناميكية.
- لا يوجد حساب مستخدم أو مزامنة سحابية؛ البيانات محلية على الجهاز.
- خيارات اللغة والثيم مثبتة حالياً على العربية والوضع الداكن، وفق إعدادات الإصدار المطلوب.


## بناء APK عبر GitHub Actions
أُضيف ملف سير عمل في `.github/workflows/android-apk.yml`. بعد رفع المشروع إلى مستودع GitHub على الفرع `main`، شغّل سير العمل من تبويب Actions (أو ادفع تحديثاً إلى main). عند نجاحه ستجد APK باسم `routine-android-release` ضمن Artifacts. هذا المسار لم يُختبر من داخل هذه البيئة، ويجب مراجعة سجل البناء إذا فشل.
